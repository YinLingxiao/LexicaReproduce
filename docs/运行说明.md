# Lexica 运行说明

## 环境

- Windows 10/11 x64
- MSYS2 UCRT64：`pacman -S mingw-w64-ucrt-x86_64-gcc mingw-w64-ucrt-x86_64-cmake mingw-w64-ucrt-x86_64-ninja`
- 依赖已放在 `third_party`，不需要另外安装：SQLite 3.49.1（amalgamation）、cpp-httplib、nlohmann/json。AI 请求使用系统自带的 WinHTTP。

## 编译

在仓库根目录运行 `build.bat`，产物是 `build\lexica.exe`，网页会复制到 `build\web`。

源码按功能集中在 `src`，前端位于 `web`。默认也构建验收测试，运行 `ctest --test-dir build --output-on-failure` 执行全部三组；测试数据写入构建目录的 `test-output`，不使用用户数据目录。只构建主程序时，在 UCRT64 环境配置 `-DBUILD_TESTING=OFF`。完整目录和模块说明见根目录 `README.md`。

## 启动

```bat
build\lexica.exe
```

浏览器打开 <http://127.0.0.1:8765>。控制台版用 `build\lexica.exe --cli`。

| 参数 | 默认值 |
|---|---|
| `--port` | 8765 |
| `--data-dir` | exe 所在目录下的 `data` |
| `--web-dir` | exe 所在目录下的 `web` |

启动时第一行输出状态。`DIR_NOT_WRITABLE`、`DB_CORRUPT`、`VERSION_TOO_NEW` 会直接退出，且不会改动已有数据库。

## 词库

从 [ECDICT](https://github.com/skywind3000/ECDICT) 获取 `ecdict.csv`，或从 release 获取 `stardict.db`，然后在设置页（或 `POST /api/import`）填写本地路径导入。重复导入不会产生重复词条，词条 ID 不变。

## AI（可选）

密钥只从环境变量读取，启动前设置：

```bat
set LEXICA_AI_KEY=你的密钥
build\lexica.exe
```

修改密钥后要重启程序。原项目把密钥存在系统凭据库，本项目为了演示改用环境变量，属于已知差异。地址必须是 `https://`，本机地址例外。

## 数据与备份

`data` 目录下的文件：

| 文件 | 内容 |
|---|---|
| `lexica.db`（及 `-wal`、`-shm`） | 词库、学习状态 |
| `ai-config.json` | AI 开关、地址、模型（不含密钥） |
| `ai-cache.json` | 合格的 AI 例句，最多 500 条 |

备份时先关闭程序，再复制整个 `data` 目录；恢复时把目录复制回去。数据库版本记在 `schema_migrations`（见 `src/dict/dict.cpp`）。旧库启动时自动升级，出现未知或更高的迁移编号会拒绝打开。

## 换电脑运行

1. 安装上面的 MSYS2 工具链，运行 `build.bat`。
2. 把 `build\lexica.exe` 和 `build\web` 复制到目标电脑。exe 静态链接，不依赖 MSYS2 运行库。
3. 需要保留学习记录时，同时复制 `data` 目录。
