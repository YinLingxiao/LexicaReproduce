# Lexica 接口说明

服务只监听 `127.0.0.1`，默认端口 8765。请求和响应都是 UTF-8 JSON。

## 通用格式

成功：

```json
{"ok": true, "data": {}}
```

失败：

```json
{"ok": false, "error": {"code": "WORD_NOT_FOUND", "message": "未找到单词"}}
```

业务错误的 HTTP 状态码也是 200，要看 `ok`。请求体不是 JSON 对象返回 400，路径不存在返回 404。`Host` 不是本机地址、或写请求带了外来 `Origin`，返回 403 `FORBIDDEN`。

| 错误码 | 含义 |
|---|---|
| BAD_REQUEST | 参数错误 |
| DICT_NOT_READY | 尚未导入词库 |
| WORD_NOT_FOUND | 未找到单词 |
| QUESTION_EXPIRED | 题目或会话已失效（重启或超过保留轮数） |
| DB_ERROR | 数据库错误 |
| AI_DISABLED | AI 未开启 |
| AI_KEY_MISSING | 未配置密钥 |
| AI_TIMEOUT | AI 请求超过 15 秒 |
| AI_INVALID | AI 地址、响应或内容不合格 |
| FORBIDDEN | 来源不被允许 |

## 状态与导入

`GET /api/status` → `{"state": "OK", "dict_ready": true}`

`state`：`OK` / `DICT_EMPTY` / `DIR_NOT_WRITABLE` / `DB_CORRUPT` / `VERSION_TOO_NEW`。

`POST /api/import`，请求 `{"path": "D:/ecdict/stardict.db"}`。支持 ECDICT 的 SQLite 版（`stardict` 表）和 CSV 版（表头含 `word, phonetic, definition, translation, exchange`）。格式不对或文件打不开直接返回 `BAD_REQUEST`。成功时立即返回任务，导入在后台进行：

```json
{"id": "i1791637877149", "status": "running", "added": 0, "updated": 0, "skipped": 0, "failed": 0, "error": null}
```

`GET /api/import/{id}` 返回同样结构。`status` 为 `running` / `succeeded` / `failed`，失败时 `error` 为 `{code, message}`。计数含义：`added` 新词，`updated` 已有词内容变化，`skipped` 内容相同或大小写冲突被舍弃，`failed` 词头为空。同时只运行一个导入，再次提交返回正在运行的任务。导入每 5000 行提交一次，失败不影响已有词条。

## 查词

`GET /api/suggest?q=ap` → `[{"id": 2, "word": "apple"}]`，最多 8 条，按单词字节序、再按 ID 排序；空前缀返回 `[]`。不记历史。

`POST /api/lookup`，请求 `{"word": "ran", "op_id": "随机串"}`：

```json
{"id": 1, "word": "run", "phonetic": "rʌn", "translation": "v. 跑", "definition": "to move fast", "query": "ran"}
```

精确匹配优先，查不到时按词形回退；`query` 与 `word` 不同表示发生了回退。同一 `op_id` 只记一次查词。空输入 `BAD_REQUEST`，未导入 `DICT_NOT_READY`，查不到 `WORD_NOT_FOUND`。

`GET /api/entry/{id}` 返回同样结构，`query` 为空，不记历史。

## 个人词汇

`GET /api/history?page=1&size=20` → `{"total": 2, "items": [{"id": 1, "word": "run", "utc": 1791637877}]}`

`GET /api/vocab?fav=1&stage=0&paused=0&q=ru&page=1&size=20` → `{"total": 1, "items": [{"id": 1, "word": "run", "favorite": true, "note": "", "paused": false, "stage": 0}]}`

`PUT /api/vocab/{id}/favorite` `{"value": true}`、`PUT /api/vocab/{id}/paused` `{"value": true}`、`PUT /api/vocab/{id}/note` `{"text": "最多 5000 字"}` → `{}`

## 复习

`POST /api/review/start` → `{"session_id": "s1791637877149000"}`

`GET /api/review/{session_id}/next`：

```json
{"has": true, "question": {"id": 1791637877149000, "session_id": "s1791637877149000", "entry_id": 2, "prompt": "an _____ fruit", "kind": "local", "practice": false}}
```

没有题时返回 `{"has": false}`。`kind` 为 `local`（释义题，优先英文释义）或 `ai`（AI 例句填空，仅在 AI 开启且有合格缓存时出现）。题干里的目标词及其变形都替换成下划线。`practice` 为 `true` 表示本轮错词重练。

`POST /api/review/question/{id}/hint`，请求 `{"level": 2}`，不传 `level` 就取下一级 → `{"level": 2, "text": "a round _____"}`

| 级别 | 内容 |
|---|---|
| 1 | 首字母加下划线 |
| 2 | 题干没用到的另一种释义（题干是英文就给中文，反之亦然） |
| 3 | 直接给出答案，本题按没掌握计 |

`POST /api/review/question/{id}/submit`，请求 `{"answer": "apple"}`：

```json
{"entry_id": 2, "correct": true, "duplicate": false, "stage": 1, "hint_level": 0, "practice": false}
```

`correct` 为答案正确且没用第 3 级提示。正式题：答对没用提示升一级，答对用了 1～2 级提示不变，否则降一级（最低 0）；下次复习间隔按阶段 0/1/2/3 为 1/3/7/14 天。正式题没掌握时，本轮追加一道重练题。重练题不改阶段，也不计入统计。重复提交返回首次结果，`duplicate` 为 `true`。

`GET /api/review/{session_id}/summary` → `{"formal_count": 4, "formal_correct": 2, "practice_count": 2, "reinforce": ["banana"]}`

`formal_count` 只统计已作答的正式题；`reinforce` 是正式没掌握、重练也没答对的词。服务端只保留最近 20 轮会话。

## 统计

`GET /api/stats` → `{"days": [{"date": "2026-10-10", "lookups": 3, "reviews": 4}], "stage0": 2, "stage1": 2, "stage2": 0, "stage3": 0, "paused": 0}`，`days` 共 14 天。

## AI

`GET /api/ai/config` → `{"enabled": true, "base_url": "https://api.example.com/v1", "model": "gpt-4o-mini", "key_configured": true}`。不会返回密钥。

`PUT /api/ai/config`，请求 `{"enabled": true, "base_url": "...", "model": "..."}` → `{}`。`base_url` 必须是 `https://`，本机 `http://127.0.0.1`、`http://localhost` 例外，否则 `BAD_REQUEST`。只支持 OpenAI 兼容的 `/chat/completions`，地址没有这个后缀时会自动补上。

`POST /api/ai/test` → `{}`。会真的发一次请求，最长等 15 秒。

`POST /api/ai/example`，请求 `{"id": 2, "word": "apple"}`，`word` 可省略，填了就必须与词条一致 → `{"id": "t1791637877149", "status": "pending", "text": ""}`

`GET /api/ai/task/{id}` → `{"id": "t1791637877149", "status": "succeeded", "text": "I eat an apple every day."}`，`status` 为 `pending` / `running` / `succeeded` / `failed`。

合格例句要求：一行、一句英文、不超过 500 字节、包含完整的目标词。只有合格例句会进缓存；缓存键包含词条、单词、释义、地址、模型和提示词版本。相同请求正在进行时直接返回同一个任务。
