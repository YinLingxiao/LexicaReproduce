# 个人词汇与统计

实现位于 `src/vocab`，构建目标为 `lexica_vocab`，依赖公共模块和 SQLite。

## 保存哪些数据

模块打开词库模块已创建的 `lexica.db`，保存收藏、笔记、暂停、查词请求编号和活动历史。建表及升级统一由词库模块管理，不会在这里新建一套数据库。

一次正式查词由 App 调用 `recordLookup`，同时创建个人词汇记录和查词事件。同一个 `op_id` 只处理一次，重启后重试也不重复记历史。候选建议和只读详情不进入历史。

收藏和暂停是开关，一个词只有一条记录。笔记按 UTF-8 字符数限制为 5000，超限时保留旧内容。中文、多行和引号通过 SQL 参数绑定保存。

## 列表与统计

`list` 先筛选收藏和暂停，再按不区分大小写的词头子串与阶段筛选。阶段通过公共 `StageSource` 接口读取，不修改复习成绩。总数是筛选后的记录数，按词条编号排列；默认每页 20 条，最多 100 条，超大页码返回原总数和空列表。

`history` 按事件倒序分页，不按单词去重。`stats` 按上海自然日输出含今天的 14 天活动，没有活动的日期补 0；阶段词数由 App 从复习模块补齐。

正式复习的状态、成绩和带 `qid` 的活动事件由复习模块在同一事务保存。`addReview(id, qid)` 可补记缺失事件，同一题编号不重复计数；旧接口 `addReview(id)` 保留。词汇模块只负责活动统计，不重新判分。

## 验收与边界

```bat
build.bat
ctest --test-dir build -R "^vocab_tests$" --output-on-failure
```

`tests/vocab_tests.cpp` 当前有 88 项检查，覆盖持久化、中文笔记、查词去重、分页边界、各项筛选、上海日期分桶和复习事件重试。测试数据保存在构建目录的独立测试子目录中。

数据库打不开时接口返回 `DB_ERROR`；`isPaused` 返回 false，`pausedCount` 返回 0。词头和阶段筛选目前仍会读取候选列表到内存。网页业务操作通过接口层全局锁串行访问本模块。
