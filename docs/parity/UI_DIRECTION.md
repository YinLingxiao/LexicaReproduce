# Current UI direction

User preference confirmed on 2026-10-30; this supersedes earlier learning-first homepage plans.

- The core product is the dictionary. Search is the first element on the Search page, followed by recent searches.
- Do not add a promotional headline, learning-flow diagram, review task card, or learning-record banner above dictionary content.
- Interface labels, settings, tooltips, accessibility labels, and application status messages are English. Chinese dictionary definitions, example translations, mnemonics, and personal notes remain content and are preserved.
- Pronunciation uses the original compact speaker icon for words and sentences. Do not replace it with a text button or persistent voice explanation.
- Keep the existing themes and saved preferences. Review, Words, and Stats remain accessible through navigation.

Verification should include the complete dictionary copy, the user's dark theme, a narrow window, and actual word/sentence playback. UI changes do not justify resetting or reimporting the user's dictionary.
